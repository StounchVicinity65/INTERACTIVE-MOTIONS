Why units can look different across simulations একই একক বিভিন্ন সিমুলেশনে ভিন্ন দেখায় কেন
Scale is for visibilityস্কেল দৃশ্যমানতার জন্য Each sim picks a pixel scale so motion fills the canvas. Physics ratios stay correct. প্রতিটি সিম ক্যানভাস পূরণের জন্য স্কেল বেছে নেয়। পদার্থবিজ্ঞান সঠিক থাকে।
Time is real secondsসময় প্রকৃত সেকেন্ড Animations use real elapsed time, so a 2 s swing takes 2 real seconds on any screen. অ্যানিমেশন প্রকৃত সময় ব্যবহার করে, তাই ২ সেকেন্ডের দোলন যেকোনো স্ক্রিনে ২ সেকেন্ড নেয়।
Trust the HUD numbersHUD সংখ্যায় বিশ্বাস করুন On-screen values are always in SI units. The canvas is only a visual aid. অন-স্ক্রিন মান সবসময় SI এককে। ক্যানভাস শুধু দৃশ্যমান সহায়তা।
Physics stays correctপদার্থবিজ্ঞান সঠিক থাকে Doubling pendulum length still changes the period correctly, regardless of pixel scale. দোলকের দৈর্ঘ্য দ্বিগুণ করলে পর্যায়কাল সঠিকভাবে পরিবর্তিত হয়।
